# Kredit Foto Sementara

Semua foto di bawah ini adalah **foto stok sementara**. Fungsinya menggantikan foto asli klien sampai aset dari MR Global tersedia. Jangan menampilkan foto ini sebagai dokumentasi event MR Global.

- Sumber: [Pexels](https://www.pexels.com/)
- Lisensi: [Pexels License](https://www.pexels.com/license/), gratis dipakai, termasuk untuk keperluan komersial, tanpa kewajiban atribusi. Kredit tetap dicantumkan di sini sebagai catatan internal.
- Foto dipotong dan dikonversi ke WebP oleh developer. Potongan tidak mengubah makna foto.
- Saat foto klien masuk: ganti file, perbarui `alt`, hapus komentar stok di view terkait, lalu hapus baris terkait dari dokumen ini.
- Kredit tidak ditampilkan di halaman. Catatan ini dan komentar HTML di dekat foto adalah satu-satunya tempat kredit.
